## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Dev server at `/` |
| `npm run build` | Production build for GitHub Pages (`/algoritmos/`) |
| `npm test` | Vitest unit tests |

## Environment

- **Dev:** `VITE_BASE_PATH=/`
- **Production (Pages):** `VITE_BASE_PATH=/algoritmos/`
