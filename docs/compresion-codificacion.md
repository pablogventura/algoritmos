# Compresión, codificación e información

## Compresión sin pérdida

- Huffman coding
- arithmetic coding
- Lempel-Ziv: LZ77, LZ78, LZW
- run-length encoding
- Burrows-Wheeler + move-to-front
- delta encoding

## Codificación de enteros

- Elias gamma/delta coding
- Golomb/Rice coding

## Corrección de errores y detección

- Reed-Solomon
- Hamming codes
- CRC

## Codificación y decodificación de canal

- Viterbi decoding
- LDPC (al menos conceptualmente)

## Nota

Para IoT no es ornamental: compresión, CRC y codificación aparecen en protocolos, firmware y transmisión ruidosa.
