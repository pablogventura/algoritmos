# Corpus de algoritmos

Mapa operativo de algoritmos y técnicas que conviene dominar: qué problema resuelve cada familia, qué garantías da, cuándo falla y qué estructuras de datos necesita.

## Referencias base

- **Introduction to Algorithms** (CLRS): referencia estándar universitaria/profesional. La 4.ª edición agrega emparejamientos bipartitos, algoritmos en línea, aprendizaje automático y arreglos de sufijos.
- **Algorithms** (Sedgewick & Wayne): algoritmos y estructuras de datos de uso actual.
- **The Art of Computer Programming** (Knuth): referencia clásica profunda.
